# UX profile (DRAFT, derived from bearing_digital_twin_website_master_prompt.md; edit freely)
- Aesthetic reference: Linear (dense, dark, 1px borders, restrained motion). Raycast-style compactness for tables.
- Banned: gratuitous glassmorphism, neon/glow borders, decorative gradients, rainbow CTAs, cartoon empty states,
  fake live-data effects, nested scrollbars.
- Accessibility: WCAG 2.1 AA (4.5:1 text, 3:1 large text/borders, visible focus, reduced-motion honoured).
- Voice: Utilitarian and minimal. State what the model said, what the physics says, and what is unknown.
- Icons: no library found in the repo; inline SVG only for now (no emoji as UI icons). Lucide is the suggested pick if one is added.
- Colour use: green = healthy only, amber = warning/demo label, orange = degrading, red = critical, cyan = neutral telemetry/accent.
- Honesty labels: Demo/Synthetic, Validation, Test, Indicative projection (never "RUL").
